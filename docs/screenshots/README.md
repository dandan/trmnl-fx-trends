# Screenshots

Every layout on every device, orientation and mode, as a record of what
the plugin looks like at a given commit. Regenerate with
`trmnl-plugin/screenshots.sh`.

[`index.html`](index.html) shows all 24 layouts on one page, numbered
1-24, with a switch between light and dark. GitHub lists it as source, so
open it from a checkout.
